# M365 Dashboard

Android-дашборд для Xiaomi M365 Pro: скорость, мощность, расход в Вт·ч/км (мгновенный и средний),
остаток энергии в Вт·ч, запас хода, напряжение ячеек и разбаланс. Без рекламы.

## Как установить

1. Вкладка **Actions** → последняя зелёная сборка «Build APK».
2. Внизу, в разделе **Artifacts**, скачай `m365-dashboard-apk` (это zip с APK внутри).
3. Распакуй на телефоне и установи APK (разреши установку из этого источника).

Новые версии ставятся поверх старой — ключ подписи постоянный.

## Что внутри (v0.1)

- Подключение по BLE (Nordic UART), протокол 55 AA, автоподключение к прошлому самокату.
- Экран «Езда»: скорость, мощность, Вт·ч/км сейчас и средний, остаток Вт·ч, запас хода.
- «Батарея»: заряд, остаток, ток, напряжение, 10 ячеек, разбаланс, температуры, циклы.
- «Самокат»: рекуперация, круиз, фонарь, блокировка, версии прошивок, журнал пакетов.

Остаток в Вт·ч считается по кривой напряжения ячеек (а не по номинальным 36 В),
мгновенный расход сглаживается по последним ~150 м.

## Сборка

Папка `android/` генерируется в CI командой `flutter create`, затем `tool/patch_android.py`
добавляет разрешения Bluetooth. Шрифт Chakra Petch (OFL) скачивается из google/fonts при сборке.
